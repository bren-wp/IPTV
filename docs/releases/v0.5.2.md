# IPTV v0.5.2 — Shared hosting and safer public playlists

**Cross-platform preview** based on the existing IPTV design and supported targets; no UI rebranding or invented channels.

## Improvements

- Publish a ready-to-upload static website with the validated catalog, read-only JSON status feeds and HTTPS HLS M3U export. A normal Apache document root needs no build tooling or server-side database.
- Harden the public M3U export against injected newlines, embedded URL credentials, private/local destinations and unsafe schemes. Reject unsafe remote channel artwork links in the export.
- Add regression tests for exported media URLs and enforce them in the platform/web deployment pipelines.
- Add Apache Content Security Policy and Permissions Policy headers while retaining required external artwork, media and HLS network requests.
- Continue the existing shared player, hourly catalog sync, fallback snapshot, bounded stream recovery and cross-platform CI builds.
- Align application/package identifiers for version 0.5.2 across platforms; Android release code 502, iOS build 7.

## Expected artifacts and their status

The preview automation publishes only after shared unit/E2E checks, platform builds and Windows launch smoke have passed. APKs are **debug-signed**; AABs and iOS Simulator bundles are **not production-signed**. Samsung is staging ZIP without publisher WGT signing. LG has a packaged IPK. Windows setup and portable EXEs are unsigned pending Authenticode. SHA256SUMS.txt lists ten distributable file hashes.

The static web snapshot is current **only as of its build**; configure the optional hourly SSH workflow to update files on shared hosting. GitHub Pages must first be enabled under **Repository Settings → Pages → Source: GitHub Actions**. A missing Pages site produces a deployment 404 and does not indicate the shared player build is broken.

Do not infer broadcast redistribution rights, availability, or compatibility from a channel's public URL. Check rights, CORS and real devices before production distribution.
