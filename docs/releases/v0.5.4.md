# IPTV v0.5.4 — Playback and XMLTV reliability

## Improvements
- Fixed a real EPG loading deadlock: when an XMLTV host times out, the guide now advances to the next published source, or reports a timeout after the final source instead of displaying an endless loading indicator.
- Cancelled stale provider results after changing channels or closing the guide, preserving channel-specific third-party programme titles and never guessing listings.
- Paused startup and stall watchdogs while the TV, phone or desktop application is hidden/suspended; re-armed appropriate monitoring after returning to the foreground to avoid false failovers.
- Excluded unsupported MPEG-DASH (.mpd) URLs from automatic retry selection; existing HLS and native media fallbacks remain in place.
- Added a no-referrer policy to externally hosted broadcaster logos for additional privacy without removing channel branding.
- Added a browser regression test for real XMLTV provider failover, plus a unit test for unsupported DASH retries.
- Version alignment: app and platforms 0.5.4, Android versionCode 504, iOS simulator/distribution build number 9, Tizen/webOS manifests and Windows Setup/Portable release names updated.

## CI deliverables (after successful merge)
Nine files and SHA256SUMS.txt: Android debug APK and unsigned release AAB, Android TV debug APK and unsigned release AAB, unsigned iOS Simulator app ZIP, Windows Setup and Portable EXEs, Samsung Tizen staging ZIP and LG webOS IPK. The shared UI build is packaged only inside installed apps, not as a public website.

## Limitations and publishing checklist
These are automated builds, not a claim of universal stream availability or pixel-perfect device verification. External hosts can block playback, CORS, DRM or regional access, and EPG services may not provide listings. Production Android and iOS distribution requires signing secrets; Samsung store-ready WGT requires its certificate and build tools; Windows publisher signing and on-device QA remain separate. Streams and logos are external services: a referrer policy does not hide the viewer's IP from hosts. No public website, web ZIP or hosting deployment is restored.
