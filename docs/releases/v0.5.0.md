# IPTV v0.5.0 — Windows desktop and resilient playback preview

**One App. Every Screen.** This update brings the verified Windows Setup and Portable apps into the same downloadable release as the Android, iOS Simulator, TV and web builds. It also adds bounded recovery for failing HLS sources and automated selection of a previously untried channel stream.

## Improvements

- Windows 10/11 x64 **Setup EXE** and **Portable EXE**, tested for successful desktop startup in GitHub Actions.
- Automatic live stream fallback: recover HLS network/media failures where supported, detect playback stalls, then try alternative stream URLs without cycling endlessly.
- New stream-failover unit tests and browser verification, plus existing TypeScript, privacy/security, catalog, EPG and platform build checks.
- Channel metadata updates on a best-effort hourly schedule; active clients refresh approximately every 15 minutes and keep a local verified catalog.
- Dedicated Android, iOS, Android TV, Samsung Tizen, LG webOS, web and Windows packaging.

## How to install

**Windows:** Download and run `IPTV-Setup-0.5.0.exe`, or use `IPTV-Portable-0.5.0.exe` without installation. Both are unsigned evaluation builds and may trigger Windows SmartScreen. Do not bypass organizational security policy; review the release and hashes before testing.

**Android:** Install the debug APK on a testing device. Unsigned AAB bundles cannot be installed as ordinary APKs and are not ready for store upload.

**iOS:** The simulator ZIP works with Xcode on macOS; a signed device IPA requires valid Apple distribution certificates, provisioning profiles and device QA.

**Samsung/LG:** LG IPK requires webOS developer tooling; Samsung staging requires Tizen Studio plus a valid TV signing certificate. Hardware/remote/codec tests are not certified.

**Web:** Extract the ZIP to an HTTPS static host. Video playback depends on each provider's rights, CORS, codec, geolocation and DRM policies.

## Release qualifications

These packages are a **GitHub prerelease**, not a guarantee of uninterrupted external TV streams or platform store approval. Playlist links are not licenses. Stream source compatibility and network access vary by device and location. The application does not rebroadcast content, bypass DRM or supply pay-TV credentials.
