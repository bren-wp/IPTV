# IPTV v0.5.1 — Resilient channel directory

**One App. Every Screen.** Maintenance preview for Android, iOS Simulator, Android TV, Samsung Smart TV staging, LG webOS, web and Windows. All platforms retain the existing unified premium interface.

## Improvements

- **Live catalog resilience.** If the primary live-directory API fails, the player now checks a validated current directory snapshot published hourly from the project's GitHub repository before trying the bundled installation snapshot.
- **Verified fallback.** The freshest usable channel directory wins unless a newer snapshot unexpectedly drops more than half of an established large directory. Invalid, empty or malformed snapshots are rejected.
- **Offline reliability.** Valid remote fallback data is also cached on the device. IndexedDB reads and writes are timeout-bounded, and stale data cannot overwrite newer stored results.
- **More regression coverage.** Unit and browser tests simulate upstream API outages, old and new snapshots, and network failure with only a bundled copy available.
- **Shared player stability.** The v0.5.0 bounded stream recovery, automated playlist checks, Windows Setup/Portable packaging, and all earlier platform features remain in place.

## Installation and limitations

Test APKs can be installed directly on testing devices; unsigned AABs cannot be used as normal APKs or uploaded as production-signed apps. Windows EXEs are unsigned and may trigger SmartScreen. iOS Simulator requires Xcode/macOS and does not install on an iPhone. Samsung Tizen requires signed WGT packaging; LG TV distribution requires hardware QA and relevant seller approvals.

Channel-directory URLs are metadata, not licenses to redistribute streams. Third-party broadcasters can restrict streams by CORS, codecs, geolocation, authentication or DRM. No guarantee of uninterrupted streaming. Production signing, device testing and content-rights review remain required. See [release readiness](https://github.com/bren-wp/IPTV/blob/main/docs/PRODUCTION_RELEASE.md).
