# IPTV v0.4.0 — Cross-platform preview

**One App. Every Screen.** This preview packages the new premium blue/navy design for Android, Android TV, iOS Simulator, web browsers, LG webOS and Samsung Tizen staging.

## What's included

- Shared responsive IPTV interface with the illustrated TV/play identity, category navigation, country filters and accessible remote/keyboard focus.
- Live channel browsing, search, favorites, recently watched, manual stream fallback and supported HLS playback.
- Optional third-party XMLTV electronic programme guide, device-local preferences and automatic channel directory refresh.
- Web, Android and Android TV installers/build bundles, iOS Simulator test bundle and Smart TV packages; all from the same tested source revision.
- Verified TypeScript/unit tests, desktop/mobile browser interaction tests, Android/iOS compilation and TV bundle/asset checks.

## Safety, content and reliability

This application is a player/directory, not a rebroadcasting service. Playback relies on third-party video sources and may be restricted by geography, CORS, DRM, codecs or provider availability. Public playlist entries are not evidence of broadcast/distribution rights. No account or built-in telemetry; favorites and viewing history (channel IDs only) stay on the device.

Production launch additionally requires store/distribution signing credentials, content licensing review, real-device QA, store/TV certification and appropriate legal notices. Use the [production release checklist](https://github.com/bren-wp/IPTV/blob/main/docs/PRODUCTION_RELEASE.md).

## Installation notes

- **Android:** download the debug APK and install only on a test device where you accept sideloading test software. The unsigned AAB is *not* an installable APK.
- **Android TV:** download the separate AndroidTV debug APK and validate launcher, remote, video and EPG on your TV.
- **iOS:** unzip the simulator artifact and use Xcode's simulator installation workflow on macOS; a signed device IPA requires Apple credentials.
- **webOS:** install the IPK with LG's supported developer tooling and test on a compatible TV.
- **Samsung:** the staging archive requires a Tizen Studio signing profile to produce a WGT.
- **Web:** host the extracted static bundle over HTTPS. Browsers may block external streams.

Do not publish these unsigned/test artifacts as official certified store packages.
