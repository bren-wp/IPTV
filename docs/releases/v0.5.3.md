# IPTV v0.5.3 — App-only distribution, more resilient EPG and playback

## What's changed
- Retired public website, public JSON/M3U feeds, browser-specific channel links, web ZIP builds, GitHub Pages and self-hosted web deployment workflows.
- Retained the common React player solely as an internal build ingredient for installed Android, Android TV, iPhone/iPad, Windows, Samsung Tizen and LG webOS apps.
- Updated the EPG's current-programme clock while the guide is open. Added bounded failover to the next real published XMLTV guide when the selected provider fails or has no programme listings. Programme titles are never generated or guessed.
- Fixed playback stall detection when the user intentionally pauses.
- Explicitly omit credentials from catalog fetches. Keep checked metadata, local favorites and last-valid catalog snapshots.
- Updated release version to 0.5.3, Android versionCode 503 and iOS simulator build 8.
- Added guide-boundary and browser-sharing removal regression tests.

## Verifiable deliverables
The preview workflow builds **nine platform packages and SHA256SUMS.txt**: Android debug APK and unsigned AAB, Android TV debug APK and unsigned AAB, iOS Simulator unsigned ZIP, Windows unsigned Setup/Portable EXEs, Samsung TV staging ZIP and LG webOS IPK. No web ZIP is included.

## External release requirements
No software update can guarantee all external streams are reachable, permitted or compatible. XMLTV programme titles are provider-supplied; source errors remain visible rather than invented. Publisher certificates, signed Android/iOS packages, Samsung Tizen WGT, physical device QA, content-rights checks and store approval are not included in ordinary unsigned CI builds. Historical older releases and previously deployed third-party hosting do not disappear when website sources are removed.
